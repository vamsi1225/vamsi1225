## 🤖 What I'm building

### [PortfolioAI](https://github.com/vamsi1225/portfolioai)
> AI agent that builds your portfolio website from your GitHub profile, automatically!!.

Paste a GitHub username. The agent scrapes your repos, has **Claude** reason about your work, picks your best projects, writes your bio, selects a theme, and deploys a live site to Vercel.

Built with **LangGraph** · **Claude API** · **FastAPI** · **Next.js 14** · **PostgreSQL** · **SSE streaming**

This is a real agent - stateful pipeline, tool-using nodes, conditional routing, reasoning before generation. Not an API wrapper.
