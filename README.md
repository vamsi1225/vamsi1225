## What I'm building

### [PortfolioAI](https://github.com/vamsi1225/portfolioai)
> A tool-calling AI agent that builds your portfolio site from your GitHub profile, no human in the loop after you paste a username.

I built this after watching friends — technical and non-technical — job hunting for months without ever finding the time to build a portfolio that actually represented their work. It calls the GitHub API to pull real repos, reasons over the work with Claude to rank and select projects, generates structured bio and site copy, then deploys a live site to Vercel end to end.

**Stack:** Python · FastAPI · LangGraph · Claude API · Next.js · TypeScript · PostgreSQL · Vercel

This is a real agent — stateful graph, tool-using nodes, conditional routing, reasoning before generation. Not an API wrapper.
